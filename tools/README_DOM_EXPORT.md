# Browser DOM Export Scripts

Simple JavaScript snippets to export the **current rendered DOM** from a web page directly from your browser.

These scripts allow you to capture the HTML that the browser sees after JavaScript execution, which is useful for:

- Web scraping experiments
- DOM inspection
- Creating offline copies of pages
- Building browser automation tools
- Extracting data from dynamic websites

No external libraries or AI tools are required.

# Usage

1. Open any webpage.
2. Open Developer Tools:
   - Chrome / Firefox: `F12` or `Cmd + Option + I` (Mac)
   - Safari: Enable Developer Menu first
3. Go to the **Console** tab.
4. Paste one of the scripts below.
5. Press Enter.
6. The browser will download the rendered page DOM as `page.html`.

# Chrome 

```javascript

(() => {
  function snapshot(node) {
    if (node.nodeType === Node.TEXT_NODE || node.nodeType === Node.COMMENT_NODE) {
      return node.cloneNode(false);
    }
    if (node.nodeType !== Node.ELEMENT_NODE) return null;

    const tag = node.tagName;
    if (tag === "SCRIPT") return null;
    if (tag === "META" && /content-security-policy/i.test(node.getAttribute("http-equiv") || "")) {
      return null;
    }
    if (tag === "CANVAS") {
      try {
        const img = document.createElement("img");
        img.src = node.toDataURL();
        img.width = node.width;
        img.height = node.height;
        return img;
      } catch (e) {
        return node.cloneNode(false); // tainted canvas — export empty
      }
    }

    const clone = node.cloneNode(false); // shallow: tag + attributes only

    if (tag === "INPUT" && node.type !== "password") {
      if (node.type === "checkbox" || node.type === "radio") {
        node.checked ? clone.setAttribute("checked", "") : clone.removeAttribute("checked");
      } else {
        clone.setAttribute("value", node.value);
      }
    }
    if (tag === "TEXTAREA") clone.textContent = node.value;
    if (tag === "OPTION") {
      node.selected ? clone.setAttribute("selected", "") : clone.removeAttribute("selected");
    }

    if (node.shadowRoot) {
      const template = document.createElement("template");
      template.setAttribute("shadowrootmode", node.shadowRoot.mode);
      for (const child of node.shadowRoot.childNodes) {
        const snapped = snapshot(child);
        if (snapped) template.content.appendChild(snapped);
      }
      clone.appendChild(template);
    }

    for (const child of node.childNodes) {
      const snapped = snapshot(child);
      if (snapped) clone.appendChild(snapped);
    }
    return clone;
  }

  const root = snapshot(document.documentElement);
  const head = root.querySelector("head") || root;
  const base = document.createElement("base");
  base.href = document.baseURI;
  head.insertBefore(base, head.firstChild);

  const html = "<!DOCTYPE html>\n" + root.outerHTML;
  const blob = new Blob([html], { type: "text/html;charset=utf-8" });
  const a = document.createElement("a");
  a.href = URL.createObjectURL(blob);
  a.download = "snapshot.html";
  a.click();
  URL.revokeObjectURL(a.href);
  console.log("saved");
})();
```

# What Does This Export?

This exports:

✅ The current DOM  
✅ Content generated by JavaScript frameworks  
✅ Dynamically loaded elements  
✅ Visible page structure  
✅ HTML after the browser finishes rendering

Example:

A React website:

```
Original Server HTML
        |
        v
JavaScript Application Loads
        |
        v
Browser Builds DOM
        |
        v
document.documentElement.outerHTML
        |
        v
Exported page.html
```

---

# Important Notes

## This is NOT the original source HTML

`outerHTML` captures the **live browser DOM**, not the raw response from the server.

For modern websites this is usually preferred because it includes:

- Loaded data
- Rendered components
- Client-side generated content
